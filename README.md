

### Questions Answer:

  - 1️⃣ What is the difference between var, let, and const?
    Ans: var can be redeclared, while let cannot be redeclared. const cannot be reassigned after declaration.

  - 2️⃣ What is the spread operator (...)?
    Ans: It is used to copy or expand values from an array or object.

  - 3️⃣ What is the difference between map(), filter(), and forEach()?
    Ans: map() creates a new array, filter() creates a new array with matching items, and forEach() just runs code for each item.

  - 4️⃣ What is an arrow function?
    Ans: An arrow function is a shorter way to write a function. Example: const add = (a, b) => a + b;

  - 5️⃣ What are template literals?
    Ans: Template literals use backticks (` `) and allow us to easily add variables inside a string using ${}.
